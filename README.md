# Lution Technologies — Website

The public-facing website for [Lution Technologies](https://lutiontech.com) — a platform for custom, fully managed applications.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- [Tailwind CSS](https://tailwindcss.com)
- [TypeScript](https://www.typescriptlang.org)
- Deployed on [Vercel](https://vercel.com)

## Local development

```bash
npm install
npm run dev     # http://localhost:3000
```

## Environment variables

Copy `.env.example` to `.env.local` and fill in the values. Never commit `.env.local`.
